# TJ Bot

[TJ 미디어](https://www.tjmedia.com/) 노래방 반주곡을 Discord에서 검색하는 봇이에요.

> **비공식 프로젝트예요.** TJ 미디어(TJ Media)와 제휴, 후원, 승인 관계가 전혀 없어요. "TJ", "TJ 미디어" 및 관련 명칭과 로고, 곡 정보의 권리는 각 권리자에게 있어요.

## 기능

| 명령어 | 설명 |
| --- | --- |
| `/검색 <검색어>` | 곡명, 가수명, 곡번호로 검색해요. 초성(`ㅇㅇㅇ`) 검색과 일본곡의 한글 발음·로마자 검색도 지원해요. 결과는 페이지로 넘기고, 검색 범위(곡명·가수·작사·작곡 등)와 국가(한국·팝·일본)를 바꿔 볼 수 있어요. |
| `/최신곡` | TJ 미디어의 이번 달 최신곡을 보여줘요. |

- 검색 결과가 없으면 로마자/가나 질의를 TJ가 색인하는 한글 표기로 바꿔 다시 찾아요.
- 정확히 일치 → 앞부분 일치 → 부분 일치 순으로 정렬해요.
- 요청 수 제한, 결과 캐시, 사용자별 쿨다운으로 TJ 서버에 부담을 주지 않도록 했어요.

## 실행하기

Python 3.12 이상과 [uv](https://docs.astral.sh/uv/)가 필요해요.

1. [Discord Developer Portal](https://discord.com/developers/applications)에서 애플리케이션과 봇을 만들고 토큰을 발급해요. 특별한 Privileged Intent는 필요 없어요.
2. 초대 링크는 OAuth2 스코프 `bot`, `applications.commands`로 만들면 돼요. 봇 권한은 메시지 보내기, 링크 임베드 정도면 충분해요.
3. 저장소 루트에 `.env`를 만들어요.

   ```env
   DISCORD_TOKEN=발급받은_봇_토큰
   # 선택: 개발용 서버 ID. 지정하면 명령어가 그 서버에 즉시 동기화돼요.
   # 비우면 전역으로 동기화되고, 반영에 최대 1시간 걸릴 수 있어요.
   GUILD_ID=
   ```

4. 설치하고 실행해요.

   ```sh
   uv sync
   uv run python main.py
   ```

`.env`와 토큰은 절대 커밋하지 마세요.

## 개발

```sh
uv run ruff check .
uv run ruff format --check .
uv run mypy .
uv run pytest
```

PR을 열기 전에 네 가지를 모두 통과시켜 주세요. CI도 같은 검사를 해요. `uv run pre-commit install`로 커밋 훅을 설정할 수도 있어요. 테스트는 인라인 HTML 픽스처와 `httpx.MockTransport`만 쓰기 때문에 실제 TJ 사이트에 접속하지 않아요.

구조와 코드 스타일은 [CLAUDE.md](CLAUDE.md)에 정리돼 있어요.

```text
main.py            봇 진입점
tj_bot/
  client.py        TJ 미디어 HTTP 접근 (세션, 요청 제한, 캐시)
  parser.py        검색 결과 HTML 파서
  translit.py      로마자/가나 → 한글 표기 변환
  models.py        Pydantic 모델과 enum
  errors.py        사용자용 오류 메시지
  ui.py            공용 Discord UI (페이지네이션 등)
  cogs/            슬래시 명령어 (/검색, /최신곡)
tests/             모듈별 테스트
```

## TJ 미디어 이용 시 유의사항

이 봇은 별도의 공식 API 없이 TJ 미디어 웹사이트의 공개 페이지를 조회하고 HTML을 해석해서 결과를 보여줘요. 그래서 다음을 알아두세요.

- **약관 준수는 사용자의 책임이에요.** 직접 봇을 운영하거나 코드를 가져다 쓰기 전에 [TJ 미디어 웹사이트](https://www.tjmedia.com/)의 이용약관과 정책(하단 링크)을 확인하고, 그 범위 안에서 사용해 주세요. 이 저장소는 TJ 미디어의 허락이나 법률 자문을 받은 것이 아니고, 이용 가능 여부를 보증하지 않아요.
- **서버에 부담을 주지 마세요.** 기본 구현은 동시 요청 수 제한, 검색·최신곡 캐시, 쿨다운을 두고 있어요. 이 값을 풀거나 우회하지 말고, 대량 수집이나 데이터 재배포 용도로 쓰지 마세요.
- **곡 정보는 TJ 미디어와 각 권리자의 것이에요.** 이 저장소는 곡 데이터를 포함하거나 재배포하지 않아요. 봇이 보여주는 정보는 질의 시점에 TJ 사이트에서 가져온 것이에요.
- **정확성을 보장하지 않아요.** 사이트 구조가 바뀌면 예고 없이 동작하지 않을 수 있어요. 응답은 신뢰할 수 없는 외부 데이터로 다루고 검증 후 사용해요.
- 문제가 있으면 TJ 미디어 측 요청에 따라 기능을 조정하거나 중단할 수 있어요.

## 개인정보

봇은 사용자 데이터를 저장하지 않아요. 검색어는 결과를 가져오기 위해 TJ 미디어에 전달되고, 짧은 시간 동안 메모리 캐시에만 남아요. 운영자가 로그를 어떻게 다루는지는 각자의 환경에 달려 있으니, 공개 서비스로 운영한다면 별도의 안내를 제공해 주세요.
